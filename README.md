Тестовое задание на вакансию Frontend разработчик для Агенства недвижимости Жилфонд

Проект написан на Vue3 с Typescript, Composition Api, используются Pinia и Axios.

В проекте настроены Eslint, Prettier, husky

Scoped стили, препроцессор SASS

Добавил адаптивность и отзывчивость вёрстки для разрешений от 600px

запросы серверу оптимизированы при помощи дебаунса и аборт-контроллера
