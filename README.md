# Тестовое задание на вакансию Frontend разработчик в Агенство недвижимости "Жилфонд"

## Стек технологий

Проект разработан с использованием следующих технологий:

- **Фреймворк:** Vue 3 (Composition API, TypeScript)
- **Управление состоянием:** Pinia
- **Запросы к серверу:** Axios
- **Линтинг и форматирование кода:**
    - ESLint
    - Prettier
- **Стилизация:**
    - Scoped стили
    - Препроцессор SASS
- **Адаптивность:**
    - Вёрстка адаптирована для экранов с разрешением от 600px

## Ключевые особенности

- **Адаптивный дизайн:**
    - Реализована отзывчивая вёрстка, обеспечивающая удобство использования на различных устройствах.

- **Оптимизация запросов к серверу:**
    - Использованы техники дебаунса и AbortController для минимизации избыточных запросов.

- **Стандарты разработки:**
    - Настроен ESLint для соблюдения код-стайла.
    - Prettier обеспечивает единый стиль оформления кода.
    - Husky предотвращает добавление некорректного кода в репозиторий.

## Установка и запуск проекта

Установить Node не ниже 18 версии

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Cheglok/EmployeeSearch.git
   cd EmployeeSearch
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите проект:**
   ```bash
   npm run dev
   ```

## Структура проекта

```plaintext
src/
├── assets/         # Статические ресурсы (изображения, стили и т.д.)
├── components/     # Переиспользуемые Vue-компоненты
├── pages/          # Основные страницы
├── stores/         # Модули Pinia для управления состоянием
├── services/       # Логика взаимодействия с API (Axios)
├── helpers/        # Утилиты и вспомогательные функции
├── typespaces/     # Типизация
└── main.ts         # Точка входа приложения
```
